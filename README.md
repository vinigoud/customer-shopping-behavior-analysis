# Customer Shopping Behavior Analysis 

## Project Overview
This project analyzes customer shopping behavior using Python, SQL, Excel, and Power BI to identify purchasing patterns, customer segments, and business insights.

## Objectives
- Analyze customer purchase trends
- Identify high-value customers
- Perform customer segmentation
- Generate business insights through dashboards
- Improve decision-making using data analytics

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib)
- SQL
- Excel
- Power BI

## Key Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Customer Segmentation
- KPI Dashboard Creation
- Trend Analysis and Visualization

## Results
- Identified top-performing customer segments
- Analyzed purchasing behavior patterns
- Created interactive Power BI dashboards
- Generated actionable business insights

- customer_behavior.ipynb
- customer_behavior_sql_queries.sql
- customer behavior dashboard.pbix
